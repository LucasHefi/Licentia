# CPL-1.0 — obsahová revize

Common Public License 1.0

Revize: **2026-09-09** · pravidlo **2026-09-09.10**.

Výsledek: **zpracována, nezařazena do průvodce**.

CPL 1.0 ukládá zdrojovou reciprocitu Program/Contributions a vlastní objektovou licenci s ochranou Contributors. Zachovává obecné copyright notices a dovoluje nové verze od Agreement Steward; hranice samostatných nederivativních modulů vyžaduje komponentový model rozsahu.

## Předmět a rozsah

§1 počáteční kód a dokumentace prvního přispěvatele a vlastní distribuované změny/dodatky ostatních. Samostatný modul s vlastní licencí je mimo Contribution pouze pokud není derivátem. Program jsou takto distribuované Contributions; Contributor je jakákoli osoba/entita distribuující Program, nikoli jen IBM.

## Udělená práva

§2a světová bezroyalty copyright reprodukce, deriváty, public display/performance, distribuce a sublicence source/object. §2b patent make/use/sell/offer/import/transfer nutný pro Contribution a kombinaci s Program v okamžiku přidání, nikoli ostatní kombinace/hardware per se. §2d znalostní prohlášení copyright oprávnění; §2c příjemce zajistí případná cizí IP práva bez garance jejich neporušení.

## Podmínky a spouštěče

§3 vlastní objektová dohoda účinně vyloučí warranty/škody za všechny Contributors, přičte odchylky pouze nabízejícímu a oznámí, že u něj jsou zdroje dostupné rozumně přes obvyklé softwarové médium. Zdroj pod CPL s každou kopií dohody; nelze odstranit ani změnit jakékoli copyright notices. Identifikovat původce Contribution. §4 komerční nabídka: obrana/odškodnění ostatních za vlastní jednání/opomenutí, výluka IP infringement, podmínky rychlé písemné notifikace a kontroly/spolupráce obrany.

## Omezení, výjimky a ukončení

§§5–6 as-is a škodové výluky s výjimkou výslovných ujednání. §7 cross/counter i přímá patentová žaloba proti Contributor pro software ruší jeho licence; žaloba proti komukoli pro samotný Program bez kombinací ruší §2b. Materiální nesoulad lze napravit v rozumné době od znalosti; pak konec, zastavit use/distribution co nejdřív, závazky a downstream přetrvají. Mimo výslovný copyright/patent grant žádné jiné IP/známkové právo.

## Verze a kombinování

§7 text dohody lze kopírovat/distribuovat, měnit jen Agreement Steward, zpočátku IBM s právem předat roli vhodné entitě. Číslovaná nová verze je volitelná pro distributora, přijatá zůstává. New York+US IP, roční žalobní lhůta a waiver jury. Vlastní objektová licence nevytváří automatickou GPL kompatibilitu.

## Překážky a navazující práce

- §§ 1, 3 definují pokrytí přes Program a Contributions a kumulativně vyloučené oddělené samostatně licencované nederivativní moduly. Přidat komponentový rozsah s touto výjimkou; současné file/library/whole-work nejsou přesnou náhradou.
