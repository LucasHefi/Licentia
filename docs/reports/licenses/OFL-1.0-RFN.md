# OFL-1.0-RFN — obsahová revize

SIL Open Font License 1.0 with Reserved Font Name

Revize: **2026-09-09** · pravidlo **2026-09-09.10**.

Výsledek: **zpracována, nezařazena do průvodce**.

Licence dovoluje fonty používat, upravovat, vkládat do jiných děl a distribuovat, ale zakazuje jejich samostatný prodej a zachovává pro ně OFL. Upravené fonty bez svolení nesmějí používat rezervovaná jména ani jejich části v žádném pojmenovacím poli. Průvodce ji nezařazuje pro nový software, protože prodejní podmínky a přejmenování vyžadují samostatné posouzení písem.

## Předmět a rozsah

OFL 1.0 z 22. listopadu 2005 pokrývá Font Software včetně fontů, dat, zdrojů, build skriptů a dokumentace a Reserved Font Names.

## Udělená práva

Grant dovoluje užití, studium, kopie, sloučení, embedding, změny, redistribuci a prodej fontů pod pěti podmínkami.

## Podmínky a spouštěče

Bod 1 zakazuje prodej samotných fontů i komponent; bod 2 dovoluje prodej s libovolným softwarem a vyžaduje copyright/licenci jako text, čitelnou hlavičku či snadno viditelná metadata. Bod 3 zakazuje upraveným fontům RFN i jeho části bez písemného svolení ve všech pojmenovacích polích. Bod 5 vyžaduje vždy OFL.

## Omezení, výjimky a ukončení

Bod 4 zakazuje použít jména autorů/holderů k propagaci změněných fontů kromě přiznání příspěvku či svolení. Porušení podmínek ruší licenci; AS IS vylučuje záruky včetně patentů a odpovědnost.

## Verze a kombinování

Volitelné písemné svolení může uvolnit RFN; jiná licence pro Font Software není dovolena a podmínky OFL 1.1 nejsou přeneseny.

## Překážky a navazující práce

- Fontová licence zakazuje samostatný prodej komponent a vyžaduje RFN přejmenování všech dotčených polí upravených fontů; před doporučením je třeba fontový model s těmito podmínkami.
