# IEC-Code-Components-EULA — obsahová revize

IEC    Code Components End-user licence agreement

Revize: **2026-09-09** · pravidlo **2026-09-09.10**.

Výsledek: **zpracována, nezařazena do průvodce**.

Licence se vztahuje jen na komponenty schválené k licencování v příslušné normě IEC a dovoluje pouze změny, které norma připouští. Vyžaduje zachovat licenční oznámení a při užití uvést IEC i číslo a rok normy. Průvodce ji nezařazuje bez určení konkrétní normy, označených komponent a dovolených úprav; obecný text tyto hranice sám neurčuje.

## Předmět a rozsah

EULA pokrývá pouze Code Components identifikované a schválené pro licencování v konkrétních IEC normách, specifikacích nebo technických zprávách.

## Udělená práva

Grant se vztahuje na licencované komponenty a jen úpravy dovolené příslušnou normou a upřesnění/opravy schválené IEC; neurčuje neomezené právo měnit jakýkoli kód.

## Podmínky a spouštěče

Redistribuce zachovává copyright, podmínky a disclaimer. Každý uživatel přiřadí komponentu IEC a určí číslo/rok normy, v kódu nebo jiném rozumném místě; formulace příkladové poznámky Please reproduce je pouze součást vzoru.

## Omezení, výjimky a ukončení

Jména IEC/přispěvatelů nesmějí bez písemného souhlasu podporovat produkt, ale normu lze citovat při tvrzení shody. AS IS vylučuje záruky/odpovědnost. Komponenty vymezují CODE BEGINS/ENDS či jiné označení.

## Verze a kombinování

Příslušná norma a schválení jsou externím vymezením grantu, nikoli alternativní licencí; konkrétní norma není v obecném EULA určena.

## Překážky a navazující práce

- Grant dovoluje jen komponenty schválené k licencování a změny dovolené neidentifikovanou IEC normou; před doporučením je třeba určit normu, její licencované komponenty a přípustné změny.
