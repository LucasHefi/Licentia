# OFL-1.1 — obsahová revize

SIL Open Font License 1.1

Revize: **2026-09-09** · pravidlo **2026-09-09.10**.

Výsledek: **zpracována, nezařazena do průvodce**.

OFL 1.1 zachovává fonty a jejich změny pod OFL, dovoluje embedding a bundling, ale zakazuje samostatný prodej fontů/komponent. Pouze výslovně rezervovaná jména jsou chráněna a zákaz platí jen pro primární název změněného fontu. Vytvořené dokumenty jsou ze same-license výslovně vyňaty.

## Předmět a rozsah

Font Software 1.1 jsou soubory držitelem výslovně vydané a označené pod OFL; mohou zahrnovat zdroje, build skripty i dokumentaci. Změna formátu a port je Modified Version.

## Udělená práva

Permission dovoluje use/study/copy/merge/embed/modify/redistribute/sell originálů a změn za podmínek. Komerce při bundlingu je povolena, samostatný prodej fontového softwaru/komponent nikoli. Patentový grant chybí.

## Podmínky a spouštěče

§1 zákaz standalone sale; §2 copyright/licence v kopiích prostřednictvím čitelného souboru/headeru/metadata. §3 pouze výslovně uvedené RFN nelze bez odpovídajícího písemného svolení použít jako primary font name změněné verze. §5 distribuce Font Software zcela pod OFL, ale vytvořené dokumenty výslovně vyňaty.

## Omezení, výjimky a ukončení

§4 zakazuje jmenné endorsement/promotion/advertising změn mimo uznání příspěvku či písemné svolení. Porušení podmínek ruší licenci; disclaimer odmítá záruky včetně copyright/patent/trademark noninfringement a škody.

## Verze a kombinování

RFN 1.1 vzniká jen výslovným vyhrazením, nikoli automaticky původním jménem, a týká se primary name, nikoli všech polí. Dokumenty nemusí být OFL; samotný Font Software nemůže mít jinou licenci.

## Překážky a navazující práce

- Fontový share-alike s výstupní dokumentovou výjimkou, zákaz samostatného prodeje komponent a podmíněné výslovné RFN nejsou přesně modelovány. Doplnit fontový rozsah a podmínky verze 1.1, bez převzetí širšího RFN režimu 1.0.
