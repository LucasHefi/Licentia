# LPL-1.0 — obsahová revize

Lucent Public License Version 1.0

Revize: **2026-09-09** · pravidlo **2026-09-09.10**.

Výsledek: **způsobilá pro průvodce podle kurátorovaného profilu**.

Lucent 1.0 dovoluje všechny distribuční formy pod LPL nebo vlastní licencí, bez zdrojové reciprocity. Příspěvek vzniká jen po výslovném neodvolatelném souhlasu a neobsahuje oddělené samostatně licencované nederivativní moduly; vlastní licence musí chránit ostatní přispěvatele.

## Předmět a rozsah

§1 šablona ORGANIZATION/OWNER pro původní software s kódem/dokumentací. Program je originál a odsouhlasené Contributions nebo části. Contribution musí pocházet od přispěvatele a být výslovně odsouhlasen; výjimka odděleného vlastně licencovaného nedervativního modulu je kumulativní. Distributor zahrnuje i modifikace a části bez Contributor statusu.

## Udělená práva

§2a celosvětově bezroyalty copyright reprodukce, změny, public display/performance, distribuce a sublicence source/object. §2b patent make/use/sell/offer/import/transfer jen vlastní Contribution a kombinace s Program v době přidání, ne další kombinace/cizí Contributions/hardware per se. §2d znalostní prohlášení dostatečných copyright práv.

## Podmínky a spouštěče

§3A zvolit LPL NEBO vlastní licenci pro libovolnou formu, přiložit zvolenou dohodu ke zdroji či jiné hmotné kopii. Vlastní licence účinně vylučuje záruky a škody jménem Contributors a přičítá rozdíly nabízejícímu samotnému. §3B výrazný YEAR/ORGANIZATION-and-others copyright; §3C identifikovat původce a souhlas s Contribution, neodvolatelný po udělení. §4 obrana/odškodnění komerčního distributora za vlastní jednání/opomenutí mimo IP nároky, při rychlé písemné notifikaci a předání kontroly/spolupráci obrany.

## Omezení, výjimky a ukončení

§§5–6 as-is a liability výjimka pro výslovná ustanovení. §2c příjemce obstará případná cizí IP práva, žádná garance jejich neporušení. §7 patentové žaloby včetně cross/counter: proti Contributor o software ruší jeho grant; proti komukoli o Program samotný bez kombinací ruší §2b. Materiální porušení s přiměřenou nápravou od znalosti; po zániku co nejdříve přestat use/distribution, závazky a downstream licence trvají. Verze1.0 nemá exportní oddíl1.02.

## Verze a kombinování

§7 OWNER může vydat novou číslovanou verzi, Contributor si může zvolit novější nebo ponechat přijatou. Placeholder STATE určuje právo při nasazení šablony, spolu s US IP, roční lhůtou a waiver jury. Žádné další implicitní IP právo/známky. §3A jiná licence i ke zdroji nevytváří GPL kompatibilitu automaticky.
