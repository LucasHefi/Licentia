Python 1.6.1 lze celosvětově užívat a měnit s copyrightem CNRI a celou smlouvou nebo přesným handle oznámením 1895.22/1013. Předávané odvozeniny obsahují stručný souhrn změn. Volba práva má zvláštní výjimku pro neoddělitelný dříve GPL materiál.

## Předmět a rozsah

§1 vymezuje Python 1.6.1 a dokumentaci; nejde o Python 1.6b1 z předchozí CNRI licence.

## Udělená práva

§2 poskytuje nevýhradná celosvětová bezroyalty práva reprodukce, analýzy, testu, veřejného výkonu/vystavení, odvozenin, distribuce a dalšího užití. Patentový grant a výslovná sublicence nejsou uvedeny.

## Podmínky a spouštěče

§2 vždy zachovává copyright CNRI 1995–2001 a smlouvu NEBO její přesný substituční handle text 1895.22/1013; alternativa se nevztahuje na copyright. §3 odvozenina zpřístupněná jiným obsahuje krátký souhrn změn. Užití/instalace/kopie či kliknutí znamenají souhlas; nejsou povinné zdroje.

## Omezení, výjimky a ukončení

§§4–5 odmítají záruky IP/vhodnosti a incidental/special/consequential škody; §6 automatická terminace při podstatném porušení. §7 přednostně federální IP právo USA, jinak Virginie bez kolizních norem; u neoddělitelného dříve GPL materiálu Virginie jen pro §§4/5/7. Žádné zastoupení/partnerství/joint venture ani CNRI trademark endorsement.

## Verze a kombinování

GPL-Compatible název odráží konkrétní výjimku volby práva v §7, není blanket závěr o libovolné kombinaci. Tento text má copyright a dostupnost others souhrnu změn, které nelze přenést zpět do CNRI-Python beta1.
