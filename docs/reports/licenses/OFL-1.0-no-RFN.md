# OFL-1.0-no-RFN — obsahová revize

SIL Open Font License 1.0 with no Reserved Font Name

Revize: **2026-09-09** · pravidlo **2026-09-09.10**.

Výsledek: **zpracována, nezařazena do průvodce**.

OFL 1.0 kryje fonty, data, kód, build skripty a dokumentaci; samostatný prodej fontu či komponenty zakazuje a fontové části zachovávají OFL. Přestože ID uvádí no-RFN, připnutý text obsahuje podmínku rezervovaných názvů a jejich širokou definici z verze 1.0.

## Předmět a rozsah

Font Software: fonty, data, zdroje, build skripty a dokumentace; Modified Version zahrnuje formátové změny i portování.

## Udělená práva

Use/study/copy/merge/embed/modify/redistribute/sell pod podmínkami1–5; patentový grant není uveden.

## Podmínky a spouštěče

1 zákaz samostatného prodeje jakékoli komponenty.2 bundling s notices/licencí v textu, čitelných hlavičkách či snadno zobrazitelných metadatech.3 změněné názvy nesmějí obsahovat RFN bez písemného svolení.5 fontové části vždy OFL.

## Omezení, výjimky a ukončení

4 jména držitelů/autorů nepropagují změněné verze mimo přiznání příspěvku nebo písemné svolení. Nesplnění kterékoli podmínky null/void; AS IS a warranty/liability včetně patent/trademark infringement.

## Verze a kombinování

Preambule dovoluje bundling/embedding s libovolným softwarem, ne jinou licenci samotných fontů. No-RFN ID se nebere jako alternativní text bez podmínky3; žádná volba pozdější OFL zde není.

## Překážky a navazující práce

- Font Software zahrnuje fontové komponenty s povinnou stejnou licencí a zákazem samostatného prodeje, ale embedding/bundling nesmí být zaměněn za copyleft celého programu. Je třeba fontový model rozsahu a prodeje.
- Podmínka3 v připnutém textu zůstává a Reserved Font Name ve verzi1.0 zahrnuje název viděný uživateli i další uvedené názvy. Je třeba doložit konkrétní název/deklaraci a vyjasnit no-RFN variantu; suffix sám podmínku neodstraňuje.
