## Předmět a rozsah

Parity 6.0.0 pokrývá software identifikovaný Contributor/Source Code, ale příspěvková povinnost sahá na další software celého pracovního postupu.

## Udělená práva

Grant dovoluje vše jinak porušující copyright přispěvatele nebo jím licencovatelné patentové nároky. Patenty jsou výslovně uděleny; podmínka 5 zakazuje patentové nároky proti komukoli kvůli softwaru a kombinacím.

## Podmínky a spouštěče

Body 1–3 vyžadují přispět změny/doplňky, kombinovaný software a software develop/deploy/monitor/run with tímto softwarem. Contribute znamená zveřejnit všechny preferované zdroje běžným volně přístupným systémem a dosud veřejně nelicencované příspěvky licencovat alespoň stejně permisivně. Bod 4 předává text, Contributor a Source Code každému příjemci.

## Omezení, výjimky a ukončení

Nevědomé porušení bodů 1–3 je omluveno přispěním nebo ukončením licencovaných činností do 30 dnů od zjištění. Bod 5 je obecný zákaz patentové žaloby; není výslovně vymezena samostatná patentová terminace. Závěr odmítá záruky a veškeré škody v zákonném rozsahu.

## Verze a kombinování

Výjimka already licensed to the public znamená, že dříve veřejně licencované příspěvky se automaticky nepřelicencují. Nejde o stejnou licenci bez výjimek nebo tvrzení kompatibility s konkrétní licencí.

## Překážky a navazující práce

- Body 1–3 vyžadují zdroje i pro software pouze vyvíjený, nasazovaný, monitorovaný či provozovaný tímto nástrojem; kontribuční relicence má výjimku pro dříve veřejně licencovaný software. Doplnit workflow rozsah, podmíněnou relicenci a pravidlo veřejného distribučního systému místo zjednodušení na whole-work same-license.
