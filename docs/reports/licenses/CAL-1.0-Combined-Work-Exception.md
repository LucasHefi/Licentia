# CAL-1.0-Combined-Work-Exception — obsahová revize

Cryptographic Autonomy License 1.0 (Combined Work Exception)

Revize: **2026-09-09** · pravidlo **2026-09-09.10**.

Výsledek: **zpracována, nezařazena do průvodce**.

CAL 1.0 s Combined Work Exception vyžaduje zdroje a autonomii každého nepropojeného příjemce i přes síť, včetně jeho User Data. Označené soubory lze spojit do jinak licencovaného Larger Work při zachování source/notices/data povinností. Pinned patentový grant3.1b je useknutý vůči primárnímu OSI znění.

## Předmět a rozsah

§§1–2 Work je software a modifikace obsahující licencovatelnou část. §4 příjemce ne-Affiliate obdrží jakoukoli část/aspekt/element distribucí, komunikací, zpřístupněním či vnímatelností fyzicky/sítí. §7.1 Affiliates zahrnují control skupinu, zaměstnance a výhradní dodavatele služeb, nikoli automaticky všechny zákazníky.

## Udělená práva

§3.1a světové bezroyalty nevýhradní povolení jakékoli nepatentové IP činnosti, §1 neomezené soukromé use/modify. Připnutý§3.1b obsahuje jen fragment claims-that-Licensor-can-license, chybí výslovná patentová action věta nalezená v primárním OSI textu; rozsah se nesmí potichu doplnit. §3.2a výslovně vylučuje patentové nároky porušené pouze další úpravou/kombinací, §7.3 bez sublicence.

## Podmínky a spouštěče

§4.1 každému recipient source kopie NEBO zdarma neomezený síťový přístup; preferred source zahrnuje comments/config/docs/help/install a nutné seeds/keys/informace pro nezávislé plné funkce. Síťový přístup po dobu výkonu práv a rok poté. §4.1.2 zachované části a změny pod CAL nebo OSI přijatou kompatibilní licencí umožňující společný object. §4.1.3 nová bezpečnostní oprava má až90denní embargo jen při významném riziku, koordinaci s dalšími Licensees a poskytnutí všem na konci. §4.2 služby musí zdarma předat dostupná vlastní User Data příjemce v obvyklé elektronické formě a neblokovat nezávislé použití/key/control. §4.3 zachovat licence/autorství/attrib a statement of use přímo nebo snadný hyperlink se source.

## Omezení, výjimky a ukončení

§4.2.2–3 žádné technické/právní omezení autonomního přístupu, vzdání moci zakázat circumvention a tvrzení vynucování cizích práv. §4.4 povinnosti jen vlastním recipients, není obecná povinnost někomu poskytovat služby. §5.2 konec při nesouladu§4, jednorázové obnovení60 dní od oznámení/vědomosti, text odkazuje na conditions§2 a oba počátky nutno zachovat. §5.3 patentová žaloba proti licensor či recipient ruší vše, výjimky administrative/declaratory/obranné counterclaims/enforcement proti již terminated, downstream při tomto důvodu trvá. §6 as-is a škody v zákonném rozsahu.

## Verze a kombinování

§4.5 Combined Work Exception jen source files označené poskytovatelem nebo výhradně z nich vzniklý object; jiný software i Larger Work celek vlastní licence, ale převzatý source/notices a plná kontrola User Data zůstávají. §2.3 licensor i recipient vymáhají specific performance. §7.2 licensor může určit jurisdikci/law prominentním notice; §7.4 vítěz včetně settlement získá náklady. §7.7 text licence CC-BY-SA4 s odlišným názvem modifikované licence, nikoli podmínka softwarového jména.

## Překážky a navazující práce

- §§ 4.1.3, 4.2 stanoví bezpečnostní embargo, export dostupných User Data a zákaz technického/právního omezování autonomie, které model neobsahuje; doplnit je spolu s file-marked Combined Work Exception. Samostatně vyřešit prokazatelně useknuté § 3.1b vůči primárnímu OSI znění upstream, nepředstírat úplný patentový grant připnutého textu.
