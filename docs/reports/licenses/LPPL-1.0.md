# LPPL-1.0 — obsahová revize

LPPL 1.0 dovoluje neměnné soubory pouze v úplné distribuci včetně dokumentace a seznamu souborů. Změny obvykle vyžadují přejmenování před úpravou, trvalý zákaz původních jmen u derivátů, změnu identifikace a chybové adresy; LaTeX .ins/.fd/.cfg mají samostatná pravidla.

## Předmět a rozsah

Preambule dovoluje libovolný i ne-TeX software označený LPPL; Program je určeno copyrightovým notice a může obsahovat jednotlivé další modifikační výjimky.

## Udělená práva

Distribution dovoluje úplné neměnné distribuce a podmíněně změněné soubory/reuse kódu, bez cenového/komerčního zákazu. Další file notices mohou změny výslovně zakázat. Patentový grant a výslovná sublicence chybějí.

## Podmínky a spouštěče

Originál musí obsahovat všechny soubory/dokumentaci a prominentní seznam pokrytých souborů. Změny jen pokud file notice nezakazuje, předem přejmenovat (leda výjimka), licencovat všechny deriváty se zákazem původních jmen, změnit identification string a existující error-report adresu, uvést původ/autorství v souboru a přiložit originál NEBO informace k jeho získání. Výjimka pro aktualizaci na identickou nejnovější verzi.

## Omezení, výjimky a ukončení

LaTeX .ins nelze upravit; .fd stejné jméno jen pro dostupnost fontů a nesmí nahradit originál; .cfg pro konfiguraci s odkazem cfgguide. Souborové modifikační výjimky se uvádějí v prominentním seznamu, nikoli jiné distribuční podmínky. Warranty odmítá záruky a náklady oprav přebírá uživatel; škody vyloučeny mimo zákon/písemnou dohodu.

## Verze a kombinování

Vzor or-later je příklad nasazení, ne automatická volba každé instance. Text dovoluje použít části jako jinou licenci jen bez dojmu LPPL. Pinned neobsahuje konkrétní souborové výjimky ani odkazované cfgguide/modguide; formálně stejná licence derivátů vyžadována není, pouze děděný zákaz původních jmen.

## Překážky a navazující práce

- LPPL 1.0 vyžaduje celé původní balení, přejmenování před úpravou a děděný zákaz původních jmen i změnu error-report adres; .ins/.fd/.cfg a další file notices mění povolení úprav. Doplnit model těchto podmínek a připnout konkrétní souborové výjimky/odkazovanou dokumentaci před doporučením.
