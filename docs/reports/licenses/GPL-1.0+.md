# GPL-1.0+ — obsahová revize

GNU General Public License v1.0 or later

Revize: **2026-09-09** · pravidlo **2026-09-09.10**.

Výsledek: **zpracována, nezařazena do průvodce**.

Historický identifikátor GPL-1.0+ představuje GPLv1 s volbou pozdější verze při příslušném licenčním oznámení. V1 vyžaduje celý distribuovaný odvozený program pod GPL, datované změny, interaktivní oznámení a odpovídající zdroje nebo konkrétní nabídku. Deprecated ID se pro nové označení nenabízí.

## Předmět a rozsah

§0 jakýkoli program nebo jiné dílo s copyrightovým oznámením GPL; work based on Program obsahuje jeho celý text nebo část, i modifikovanou. §2 výjimka pouhé agregace nezávislé práce na médiu.

## Udělená práva

§§1–3 kopie, modifikace a zdrojová/binární distribuce, s poplatkem za fyzický přenos a volitelnou placenou zárukou. Preambule potvrzuje prodej; patentová práva ani patent retaliation ve v1 uvedeny nejsou. §6 příjemci dostávají práva přímo od původního poskytovatele, nikoli neomezené sublicence.

## Podmínky a spouštěče

§1 na kopiích copyright a disclaimer, zachovat GPL/no-warranty notices a předat text. §2a datovat a výrazně značit souborové změny; §2b celé publikované/distribuované obsahující dílo zdarma licencovat všem pod GPL. §2c modifikovaný běžně interaktivní program při obvyklém spuštění vypíše copyright, warranty či vlastní záruku, redistribuční právo a získání licence; nemá pozdější výjimku pro původní program bez banneru. §3 binárky s úplným source NEBO nejméně tříletou písemnou nabídkou komukoli za nominální distribuční náklad NEBO jen NC předání obdržené informace, pokud příjem byl pouze objekt/executable. Source zahrnuje všechny moduly, kromě OS standardních knihoven/headers/definitions.

## Omezení, výjimky a ukončení

§4 neoprávněná kopie/změna/sublicence/distribuce/transfer automaticky ukončuje práva, plnící downstream zachován. §6 žádná další omezení. §§9–10 výluka záruk/škod s mezemi práva či písemné dohody. Přílohové doporučení umístit notice na začátek je návod, nikoli další varianta grantu.

## Verze a kombinování

§7 pozdější FSF verzi lze zvolit, pokud oznámení říká any later version; při žádném čísle kteroukoli vydanou. §8 jiné distribuční podmínky žádají individuální souhlas autora/FSF, nikoli automatický přechod. Deprecated GPL-1.0+ nahradit přesným moderním GPL-1.0-or-later podle skutečného notice.

## Překážky a navazující práce

- SPDX označuje GPL-1.0+ jako deprecated. Při novém označení ověřit skutečnou doložku any-later-version a použít GPL-1.0-or-later; historický ID nezpřístupňovat jako novou volbu.
