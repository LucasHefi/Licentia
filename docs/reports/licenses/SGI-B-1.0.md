# SGI-B-1.0 — obsahová revize

SGI Free Software License B v1.0

Revize: **2026-09-09** · pravidlo **2026-09-09.10**.

Výsledek: **zpracována, nezařazena do průvodce**.

SGI-B 1.0 dovoluje kopie, změny a distribuci s omezeným patentovým grantem, ale vylučuje hardwarové implementace algoritmů. Změny musejí plně odpovídat rozhraním určeným v dalších oznámeních; jiná licence je možná jen při zachování vyjmenovaných podmínek. Text navíc vyžaduje hlášení cizích nároků SGI, právní ujištění a široké odškodnění. Nevyplněné požadavky na rozhraní a další závazky brání zařazení do průvodce bez posouzení konkrétního kódu.

## Předmět a rozsah

SGI Free Software B 1.0 z 25.1.2000 pokrývá Original Code a Modifications definované po souborech a může se použít v Larger Work.

## Udělená práva

§2.1 dovoluje reprodukci, distribuci, deriváty, zobrazení a výkon, spolu s patenty ztělesněnými v Original Code; §2.3 však oba granty vylučuje pro hardwarové implementace algoritmů a §2.4 dovoluje změny jen při úplné shodě s API uvedenými v Additional Notice Provisions.

## Podmínky a spouštěče

§3.A zachovává Exhibit A v každém komentovatelném zdrojovém souboru a notice s licencí v dokumentaci binární distribuce, včetně dalších konkrétních notices. §3.B nabízí původní licenci, upravenou identitu poskytovatele nebo jinou licenci s povinně nezměněnými §3,4,6,7,10,12,13 a zřetelným přiřazením odchylek příjemci. §7 vyžaduje rychlé oznámení cizích IP nároků SGI; §11 obecnou obhajobu a odškodnění za použití, změny a distribuci, §3.C navíc za alternativní podmínky.

## Omezení, výjimky a ukončení

§6 obsahuje výslovné ujištění o dodržování všech zákonů/exportu a zakazuje distribuci porušující cizí IP či jakékoli příslušné záruky. AS IS a výluka škod zachovávají zákonnou výjimku újmy na zdraví; žádná známková práva. Po nenapraveném porušení do30 dnů končí grant, řádné podlicence přežijí. §12 dává vládním uživatelům pouze zdejší obchodní softwarová práva, §13 určuje Kalifornii a náklady neúspěšné strany.

## Verze a kombinování

§8 dovoluje pozdější verze SGI, ale zde je hodnocen plný obsah1.0. Alternativní licence musí zachovat vyjmenované normativní oddíly; pouhá možnost jiné licence nedokazuje obecnou kompatibilitu.

## Překážky a navazující práce

- §2.3–4 vylučují hardwarové implementace a podmiňují změny úplnou shodou s API z dosud nevyplněných Additional Notice Provisions; model musí zachytit tuto funkční podmínku a pro konkrétní kód získat závazné API notice.
- §3.C,6,7,11 vyžadují právní ujištění, hlášení IP nároků a obecné odškodnění; známé notice a defend-added-warranty tyto povinnosti nevystihují.
