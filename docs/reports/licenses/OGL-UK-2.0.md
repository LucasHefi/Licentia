# OGL-UK-2.0 — obsahová revize

Open Government Licence v2.0

Revize: **2026-09-09** · pravidlo **2026-09-09.10**.

Výsledek: **způsobilá pro průvodce podle kurátorovaného profilu**.

OGL 2 dovoluje trvalé komerční i nekomerční užití copyrightových/databázových informací včetně source code s povinnou atribucí a pokud možno odkazem. Při chybějícím textu nebo nepraktickém množství zdrojů dovoluje souhrnné oznámení. Vyjmenovaná práva a informace, včetně patentů, jsou vyloučena.

## Předmět a rozsah

Information výslovně zahrnuje obsah, data i source code poskytované oprávněným Information Providerem; grant není automaticky ke všem Crown či neveřejným materiálům.

## Udělená práva

Using Information uděluje celosvětovou bezroyalty trvalou nevýhradní licenci copy/publish/distribute/transmit/adapt a komerčně/nekomerčně combine/include. Patenty, známky, design a neoprávněná cizí práva jsou explicitně vyňaty. Závěr dovoluje u adaptací CC-BY4.0 nebo ODC-By při splnění jejich podmínek.

## Podmínky a spouštěče

Při užití dle široké definice povinně uvést poskytovatelův attribution statement a kde možno link licence; při chybějícím statementu NEBO nepraktických četných zdrojích lze náhradní Contains public sector information licensed under OGL v2.0. Nevyžaduje plný text licence, zdroje nebo same-license.

## Omezení, výjimky a ukončení

Vyňata osobní/nepublikovaná neoprávněně dostupná data, loga/crests/Royal Arms mimo integrální dokumentovou/datovou část, military insignia, identity documents a další práva. Žádný official status/endorsement. Porušení ruší i podobné licence poskytovatele. As is, bez záruk/odpovědnosti/chybové odpovědnosti i příslibu další dodávky; právo dle sídla poskytovatele, není-li určeno jinak.

## Verze a kombinování

About výslovně říká, že adaptované informace licencované CC-BY4.0 nebo ODC Attribution splní OGL podmínky dodržováním těchto licencí. Pozdější OGL se může vydat, ale stávající informace nadále podléhají použité starší verzi: nejde o automatické or-later.
